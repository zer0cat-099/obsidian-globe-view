# Globe View

Obsidian 데스크톱에서 볼트의 세계지도를 3D 구로 열고, 원하는 위치에 노트 링크를 꽂을 수 있습니다.

## 사용법

1. 왼쪽의 **Globe View 열기** 아이콘이나 같은 이름의 명령 팔레트 항목을 선택합니다.
2. **지도 선택**으로 볼트의 이미지 파일을 연결합니다. **설정 → Globe View**에서도 지도를 변경할 수 있습니다.
3. 드래그로 회전하고 마우스 휠로 확대합니다. 지도에 초점을 두고 방향키로도 회전할 수 있습니다.
4. **마커 추가**를 누르고 구 표면을 클릭한 뒤 연결할 Markdown 노트를 검색합니다. 추가한 마커를 클릭하면 새 탭에서 그 노트가 열립니다.
5. 마커를 우클릭하고 **마커 삭제**를 선택하면 지도에서 해당 마커가 사라집니다. 연결된 노트는 볼트에 남습니다.

전 세계를 가로로 펼친 등거리 원통형 지도에 맞춰 이미지를 입힙니다. 연결할 자오선이 이미지 안쪽에 있다면 설정의 **가로 표시 범위 (%)**에서 좌우 경계를 지정할 수 있습니다. 마커는 원본 이미지 위치에 저장되므로 표시 범위를 바꿔도 같은 장소에 남습니다. 설정과 마커는 설치한 볼트의 플러그인 데이터에 저장됩니다.

## 빌드와 설치

Node.js 22.18 이상과 WebGL 2를 지원하는 Obsidian 데스크톱 1.8 이상이 필요합니다.

```sh
npm ci
npm test
npm run build
```

`dist`의 `main.js`, `manifest.json`, `styles.css`를 볼트의 `.obsidian/plugins/globe-view/`에 복사하고, Obsidian의 커뮤니티 플러그인에서 **Globe View**를 켭니다. 지도와 노트는 볼트의 파일을 사용합니다.
